# Tek Çorap Kayıp Masası

TentiAŞ Çamaşır İstihbarat Dairesi, Eskisehir 4. Ağır Çorap Mahkemesi yan odası.

Bu depo bir şakadır. Kod gerçekten çalışır. Çorap gerçekten kaybolmaz, sadece dosya numarası alır.

## Görev

Çamaşır makinesine iki çorap girer. Biri çıkar. Diğeri ne meclise, ne çekmeceye, ne de komşunun balkonuna aittir. Daire, kaybı resmi tutanağa bağlar, dönüş yönü için gösteri referandumu açar ve sonucu zaten bilen tambura saygı duyar.

Patates yoktur. Simit yoktur. Asansör yoktur. Sadece tek kalan çorap ve onun hukuki statüsü vardır.

## Kurulum

Python 3 yeter. Bağımlılık yoktur, çünkü çorap da tek başınadır.

```bash
python3 corap_masasi.py --demo
python3 corap_masasi.py --renk lacivert --program 60 --adet 2
```

## Resmi çıktı

Script şunları yapar:

- çift çorabı dosyaya alır
- kayıp olasılığını program süresine göre hesaplar
- üç sandık açar: saat yönü, ters yön, çekmece altı
- sandık kapanmadan önce tamburun kararını not düşer
- tutanak basar

## Copilot notu

GitHub Copilot bu dosyayı incelemedi. İnceleseydi muhtemelen `pass` yazıp çay molasına çıkardı. Biz onun yerine kayyumu oturttuk.

## Gizli dosya

`.gizli/sandik_notu.b64` süs değildir. Base64'tür. Merak eden çözer. Merak etmeyen çorabını aramaya devam eder.

## Lisans

Kamu malı değildir. Tek çorap malıdır. İsteyen çatallar, çatal da tek kalır.
